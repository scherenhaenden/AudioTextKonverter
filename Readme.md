# MagnetarAion

MagnetarAion is a multi-platform application for audio-to-text and text-to-audio transformations, using both cloud APIs and local LLMs.

This repository contains the following components:

-   `core`: The core logic of the application, shared between the `api` and `cli` packages.
-   `api`: The backend API, built with FastAPI.
-   `cli`: A command-line interface for the application.
-   `web`: The frontend application, built with Angular.
