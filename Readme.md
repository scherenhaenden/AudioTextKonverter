# MagnetarAion

MagnetarAion is a multi-platform application for audio-to-text and text-to-audio transformations, using both cloud APIs and local LLMs.

This repository is a monorepo that contains the following packages and applications:

## Packages

-   `packages/core`: The core logic of the application, shared between the `api` and `cli` packages.
-   `packages/api`: The backend API, built with FastAPI.
-   `packages/cli`: A command-line interface for the application.

## Applications

-   `apps/web`: The frontend application, built with Angular.
